# Worked example — evidence without taking the author's decision

**Real prepared case:** [the open-rulings brief](../../reports/OPEN-RULINGS-2026-10-13.md)
contains a staged Fire Phoenix numbering option and the evidence needed to apply
it. A ready mapping is not approval.

1. Identify the live published sequence separately from the candidate V2 line.
2. Read the local manifest, approval status, source and proposed mapping.
3. Describe exactly what the option would move and which views would regenerate.
4. Keep the existing state unchanged; ask for the specific pending ruling.
5. Leave the next agent the brief path, base revision, unchanged boundaries and
   the next safe action: obtain the ruling, then revalidate the mapping.

**Failure avoided:** turning an agent recommendation into accepted numbering
because the work was ready or because the user asked for general cleanup.
