# THE MISTAKE ATLAS
### Every mistake ever paid for across the house, organised by *class*
**Collected 2026-10-11** · 17 ledger sections · 109+ catalogued rows · 3 serials' full failure logs · 2 months

---

## WHY THIS FILE IS ORGANISED BY CLASS, NOT BY PROJECT

The house already keeps its mistakes by *where they happened* — the Golden Lion's strikes, the Tianyu post-mortem, the Fire Phoenix disaster, the GitHub audit. That is the right way to keep **receipts**.

It is the wrong way to keep **lessons**.

Because the same eight shapes keep returning, wearing different clothes. A stale number in a status panel and a stale chapter count on a profile are *the same mistake*. A gate that can't fire and a gate scoped to the wrong files are *the same mistake*. Until they are filed together, each one gets fixed alone and comes back.

This file files them together. **Every mistake below is one of twelve recurring classes.**

**The house's own conclusion, verbatim:** *the author's strikes are the curriculum.* Every standing law in the workspace was born from a verbatim strike, preserved word-for-word.

# CLASS 1 · ASSERT-WITHOUT-VERIFYING
> *Stating something as fact without having actually read the thing that would confirm or deny it.*

**Why it is the most dangerous class:** it produces *confidence without evidence*. The output looks finished. Nothing about it signals that it was never checked.

| # | Instance | What happened | Law born |
|---|---|---|---|
| **D2** | **The false assertion** | "The purple-ring skill evolution is unwritten" was asserted in **four documents** — without reading ch40, where it was already on-page. The agent's own words on retraction: *"I propagated a stale line… the exact assert-without-verifying failure this project keeps catching."* | Read before asserting. Retract in the same file the lie lives in |
| **E1** | **"Canon integration — you completely failed."** | A chapter-2 scene staged from memory that **never happened in the source** — described as *"plausible-looking fiction… called verified."* | **Canon ledger + primary text.** Never stage canon from memory |
| **E5** | **The duke's-bastard leak** | A knowledge leak of a canon secret sitting inside a limited POV — **in the same chapter whose footer claimed no invented canon specifics.** Found only by a cold full read; **no gate caught it** | Firewalls are not greppable. Some checks require re-reading |
| **D7** | **Canon gaps held open** | ch28 missing; ch1–22 not held; 337–600 only skimmed — all three recorded honestly rather than hidden | **Gaps are declared, not papered over** |
| **nn-2** | **The rigorous-artifact rule** | A "+1" numbering inference was wrong. A structured index (weak evidence) had been trusted as truth, forcing three files to be renumbered and a missing canon chapter to be fetched | **No map, index, or structured claim is trusted until verified against a second independent source or a direct fetch.** *Inference is labelled inference until then* |
| — | **The general form** | *Structured confidence from weak evidence is not truth* | — |

**The countermeasure, mandatory:** before logging any defect or fact, **try to disprove it.** Spend one call proving yourself wrong.

### The lesson this class teaches above all others

> **The prose laws police words and sentences. Nothing polices *register*. Poetry can be built from lawful words.**
>
> *The cure is the reader's experience: clear, clean, understandable — **a sentence that must be read twice is wrong no matter how lawful its words.** The pacing law compresses TIME, never SCENE.*

And the sharpest single lesson in the whole atlas:

> **When the author says "go see how canon is written," GO SEE — fetch the source, quote it, derive the rules from receipts. Two strikes were spent guessing at a target that was one fetch away.**

### The four rules that close this class

1. **One authority per fact.** Every fact has exactly one authoritative file. Everything else derives or points
2. **Nothing that can be derived may be typed.** If it can be computed, compute it
3. **Pin the count, or don't state it.** A number stated in prose must be re-measured when the thing it counts changes — **or stated timelessly**
4. **When two copies disagree, the receipt wins**

> **The parser corollary:** a derived document must be **regenerated, not hand-edited.** If you find yourself editing generated output, **you have found a defect in the generator.**

# CLASS 6 · CHECKERS THAT LIE
> *A gate that cannot fail is decoration. A gate that fails correct work is worse than no gate — it trains everyone to ignore it.*

| # | Instance | What happened | Fix |
|---|---|---|---|
| **B8** | **The check that could never fire** | The one-sentence-paragraph check stripped trailing punctuation first and **could never trigger**. Meanwhile footers claimed "no one-sentence paragraphs" while the chapters carried them | An honest tool was written instead. Ruling: short one-line beat paragraphs **are** house style — the 60-word cap is the real rule |
| **E6** | **The gate-wording bug** | The rule written to catch a knowledge-leak class was **gated on the wording of one fix — and the fix itself re-broke it** | *"Make the rule catch the mistake-class, not the wording of one fix."* |
| **I1** | **The scanner that knew one project** | Hardcoded to 11 project-specific filenames → a project declaring firewalls elsewhere read as **"zero firewalls"** and FAILED | Generalised; the FAIL→PASS resolution became a published case study |
| **N2** | **Blue Silver was never actually gated** | The unified gate classified chapters by the path substring `/chapters/` — so it swept the **author-rejected first draft** (correctly failing 29 gates) and **never saw the live Book One** at all. *The gate's "failure" was the rejected draft failing while the real text went unchecked* | Discovery generalised; the live Book One **gated for the first time: PASS** |
| **—** | **The 15 false positives** | The verifier was run against a proven 33,000-word serial and reported **15 failures. All 15 were false positives from an over-broad rule. The serial was correct and the gate was wrong** — and nothing revealed that except a hand-built negative test | **Selftest law** |
| **D3** | **The 612 parser lesson** | A "retired number" gate hit the digits **612 inside the number 2,612** | Parser lesson logged; substring discipline enforced |
| **O1** | **The substring law** | A retired-word collision: *'the white' inside 'the whiteness'* | The checker enforces substring discipline |
| **I2** | **Stale pre-prose headers** | One project's HANDOFF said "no prose yet" and START_HERE said "do not write Chapter 1 yet" — **both sitting above their own contradicted later sections** | Corrected; project now gate PASS |

### The rules that close this class

> **A check must not match its own description.** If a gate fires on the documentation *of the gate*, the gate is scoped wrong — **not the documentation.** Fix the scope, because *"just reword the docs"* **leaves the trap armed for the next file.**

> **Run the selftest after every edit to the checker.** If you add an eighth gate, **add an eighth fixture.** A gate with no fixture is a gate you are hoping works.

> **A gate that has only ever been seen to pass is a gate nobody has tested.**

**The four self-referential false positives actually recorded:**
1. A non-ASCII gate flagged the em dashes *in the law that explained the rule*
2. A placeholder match flagged the word "placeholder" *in a sentence saying "no placeholder text left"*
3. A placeholder gate applied to templates flagged *every slot token in every template*
4. A placeholder gate applied to an audit log flagged `TODO/FIXME/TBD = 0` — **the log reporting it had found none**

# APPENDIX A · THE EIGHT META-LESSONS
*The house's own summary of the shapes its mistakes keep taking.*

1. **Assert-without-verifying** → the cure is the canon ledger + primary text
2. **Inventing instead of sourcing** → the cure is canon-first, ask never
3. **Centering the OC in canon's house** → the cure is the Multi-Panel Law
4. **Prose register drift** → boring, bloated, coded, jewelled, or tic-ridden. **Six laws now police it**
5. **Two-copies rot** → *every stale number in this workspace was a second copy drifting.* The cure is one truth + drift scans
6. **Checkers that lie** → a gate that can't fire, a rule gated on one fix's wording, a scanner that knows one project's filenames. The cure is the selftest + independent drift scan
7. **Cleanup that cuts the wrong thing** → byte-verify **before** removal; unique content is kept even when it looks like a twin
8. **The author's strikes are the curriculum** → every standing law was born from a verbatim strike preserved word-for-word
